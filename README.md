# DevOps Tutorial

![Shell Scripting](https://img.shields.io/badge/Shell%20Scripting-121011?style=for-the-badge&logo=gnubash&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=for-the-badge&logo=docker&logoColor=white)

A beginner-friendly collection of DevOps learning code and small practical examples. This repository is focused on tutorials and hands-on practice; it is not a production application.

## Contents

### [Shell Scripting](./Shell-Scripting)

Bash exercises, arranged from basics to variables, conditions, loops, functions, arguments, and file handling. See its README for the complete topic list and run instructions.

### [Docker](./Docker)

Containerized Flask, React/Node.js, and ASP.NET MVC applications. See its README for the projects, ports, requirements, and Docker commands.

## Learning path

1. Start in [`Shell-Scripting`](./Shell-Scripting) and run the files in numerical order, beginning with `01_GettingStarted.sh`.
2. Move to [`Docker`](./Docker) to understand images, containers, Dockerfiles, and Compose.
3. Explore the application folders and build/run their Docker examples to practise packaging real applications.
4. Change a small part, rebuild, and repeat; the examples are intended for experimentation.

## Prerequisites

- A terminal with Bash (Git Bash, WSL, or Linux/macOS)
- Docker Desktop for the Docker exercises
- Optional: Node.js, Python, or .NET to run an application outside its container

## Repository scope

The code here supports DevOps learning: scripting, containerization, and running sample services. Each folder is self-contained, so you can learn one topic at a time.

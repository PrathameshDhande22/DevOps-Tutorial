# Shell Scripting Tutorial

Shell scripting exercises written in Bash. The files are numbered so they can be followed in learning order.

## Topics covered

| Files | Topic |
| --- | --- |
| `01` - `02` | Getting started and comments |
| `03` - `07` | Variables, constants, arrays, key-value data, and strings |
| `08` - `14` | User input, operators, and conditional statements |
| `15` - `18` | `for`, `while`, and `until` loops |
| `19` - `20` | Functions and command-line arguments |
| `servers.txt` | Sample input file used by the file-loop example |

## How to use

1. Install Bash. On Windows, use Git Bash or WSL; Bash is already available on most Linux and macOS systems.
2. Open a terminal in this directory.
3. Run an example by its file name:

```bash
bash 01_GettingStarted.sh
```

Run the files in numerical order. Some scripts accept input or arguments, so read the short comments in the file before running it.

> Tip: Make a copy before editing an exercise so you can experiment freely.
